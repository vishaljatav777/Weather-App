# 🌦️ React Weather App

A simple, responsive weather application built with React that lets users check the current weather of any city in real time using the OpenWeatherMap API.

## 🚀 Features

- 🔍 Search weather by city name
- 📍 Get current location weather using Geolocation API
- 🌡️ Displays temperature, humidity, wind speed, and weather conditions
- 🌓 Dynamic UI updates based on weather data
- 🎨 Responsive and clean UI design
- ❌ Error handling for invalid cities and API issues

---

## 🧰 Tech Stack

- **Frontend:** React, CSS Modules / Tailwind / Styled Components (optional)
- **API:** [OpenWeatherMap API](https://openweathermap.org/api)
- **Build Tool:** Vite or Create React App
